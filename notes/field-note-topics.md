# Field Note topics: the approved list

James approved this list on 28 Oct 2026. The Wednesday routine takes its topic
from here, not from the Sunday Brief. A Sunday Brief idea joins this list only
after James approves it.

## Why this list exists

By issue 11, four of the last six issues were about checking paperwork or
money, and two were about bills. James said the notes had become boring and
too narrow. A Field Note is free, so each one has to be worth a client's ten
minutes. What he asked for:

- Variety. Work and life, not only work.
- High value. No novelty or "fun" prompts.
- Broad. One prompt covers a whole family of situations ("explain any document
  you don't understand"), never one narrow case ("a letter from the tax
  office").
- Push what AI can do now: reading your email, working on your files, running
  on a schedule.
- Every issue says which tool to use and what it needs connected.
- Every issue that touches files, email or a calendar carries a plain warning
  about what it will and won't do, and the prompt itself says it.

## How the routine uses it

Take the first topic marked `next` in the next group in the rotation. The
groups run in turn: A, B, C, D, then A again. Never run two issues in a row
from the same group. Mark the topic `done NN` (the issue number) in the same
commit as the issue. If every topic in a group is done, skip that group and
say so under MAKE A DECISION ON EACH ITEM BELOW, with three new topics for that
group for James to approve.

The topic is a starting point. Build the best prompt for it to the standards in
`notes/prompt-review-standards.md`. Use a shelf card when one fits; otherwise
write the prompt fresh and list it in the email as a card for the shelf.

The rotation stands at: last issue was group A (issue 11). Next is group B.
