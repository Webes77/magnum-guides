Magnum AI Weekly Field Note / No. 12

Tired of re-explaining tasks to AI? Set them up once

What it is
A copy-and-paste prompt for any task you do over and over, like the staff roster, your social posts or the family meal plan.
What you get
You stop explaining it. It asks about the task once, then does it your way every time.
What you do
  1. In Claude or ChatGPT, make a new project, a saved space with its own instructions, named after the task. No projects? Use a normal chat and keep what it writes in a note.
  2. Open a new chat in the project, paste the prompt and answer its questions.
  3. Try what it writes on one real example of the task, then save it in the project’s instructions. About twenty minutes.
The prompt
You are an experienced trainer setting someone up to do one regular task properly. You ask before you write anything down.

The task I want set up is: [the task you repeat]. Some background: [your business and who it serves, or your household].

Interview me so you can write the instructions for a project that does this task the same way every time. Ask one question at a time and wait for my answer before the next. Cover:
1. What I hand you to start, like rough notes, a photo, a list or a form.
2. What a good finished result looks like. If I have a real one I'm happy with, I'll paste it in, because one real example beats a description.
3. Who reads it.
4. What it must always include.
5. What it must never do or say, like promising results if I'm a health business.
6. How I sound. I'll paste one message I've sent, or give you three words.
Ask one or two more questions only if an answer needs it.

Rules, and why each one is there:
- Use only what I tell you. An invented number, step or promise in these instructions repeats every time, so if something is missing, ask, and if I skip it, leave it out.
- Leave out anything that changes often, like prices and dates, because it goes out of date. Tell me which details belong in a file I upload to the project instead.
- Write the instructions as plain rules with the reason attached, written to the AI, so they still work on cases neither of us thought of.
- Have it write as me, in my words, with no exclamation marks or pet names unless I use them, because those are what make it sound like AI.
- Include a rule that it never makes up a number, name or date. If one is missing, it marks it [ASK] and tells me.
- Keep them under 300 words, because short instructions get followed and long ones get skimmed.

When the interview is done, give me:
THE INSTRUCTIONS: the full set, ready to copy and paste.
WHAT I GUESSED: up to three lines, so I can correct them.

Then ask me for one real example of the task to try them on, plus any file it needs, like a checklist, a menu or a price list. Remind me to take out names and any health or money details first. Do that task using only the instructions, then tell me the one change to the instructions that would have made the result better.

Why it works

A good café doesn’t rely on whoever’s on shift remembering the big breakfast. The recipe card is on the wall. A project is that card for your AI: written once and read before every task.
