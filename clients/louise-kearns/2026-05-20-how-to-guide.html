The 3 Biggest Mistakes That Kill AI Output

1. No foundation before you start

Most people open a new chat and ask a question cold. The AI doesn't know who you are, what you need, or how you want it to behave — so it guesses. Build the ground rules first (your role, your business, your preferences) and every output improves immediately.

2. One-shot prompting

Typing a single sentence and hoping for the best. The AI has trillions of examples of language — the more context you give it, the more specific the output. Richer input, better result. Every time.

3. Memory bloat

When a chat gets too long, the AI can't see the beginning of the conversation anymore. It starts making mistakes, looping, or losing context — this is called memory bloat. Fix: start a new chat for each fresh task. If you're deep in a chat and it starts spinning, copy the whole conversation, paste it into a new chat, and ask it to pick up from there.

Quick check: Feeling like your AI has amnesia? Ask it directly: "How are we going for context memory right now?" It'll tell you — and can write a handover brief for the next chat if needed.

The 6 Lever Framework — Better Prompts Every Time

Instead of one vague sentence, structure your prompts across six levers. You don't need all six every time — but the more you include, the sharper the output.

Role

Who is the AI being? Invoke a specific expert.

Context

What's the situation? Give it background.

Constraints

What should it NOT do? Be explicit.

Tone

How should it sound? Formal, casual, direct?

Format

How should it be structured? List, paragraph, table?

Output

What exactly do you want delivered?

Perway Example — Social Media

Weak prompt (2 levers):

Write me some Facebook posts about our latest finished home.

Strong prompt (6 levers):

You are a social media content strategist with 10 years of experience working with residential construction businesses in Western Australia. I run Perway Construction — a custom home and renovation company. We've just completed a project and I want to turn it into a week of social content across Facebook and Instagram. Don't use generic captions. Focus on the craftsmanship and the client's story. Write in a warm but professional tone. Give me 5 posts — one per day — as a simple numbered list.
Tip: Talk to the AI rather than type. Your spoken words are more natural and give it more to work with. Use WhisperFlow (see below) and just speak your prompt — the AI understands rambling better than finely typed sentences.

Setting Up Claude Correctly

Privacy settings — do this now

  1. Go to Settings (bottom left in Claude)
  2. Click Privacy
  3. Turn OFF "Improve Help Improve Claude" — this stops your conversations being used for training
  4. Review your memory settings — check what Claude has stored about you and clear anything inaccurate

Capabilities — turn these on

  1. Go to Settings > Capabilities
  2. Turn on Search and reference past chats — lets Claude search your conversation history
  3. Turn on Generate memory from chat history — builds a profile of you over time
  4. Set Tool access mode to "Tools already loaded" — faster performance

Import your ChatGPT memory into Claude

  1. Go to Settings > Capabilities
  2. Click Import memory from other AI provider
  3. Copy the prompt it gives you
  4. Paste it into ChatGPT and run it
  5. Copy the result back into Claude and click Add to Memory

Managing AI usage — Sonnet vs Opus

Check your usage at Settings > Usage. Sonnet is the right model for 90% of tasks — it's fast and cost-efficient. Opus (also called Advanced Thinking) is powerful but burns through credits quickly. Don't leave it toggled on by default.

For a team: check that staff are defaulting to Sonnet, not Opus. One person on Opus all day can burn through a month's budget.

Claude Chat vs Projects vs Cowork

Claude Chat

Conversational. One task at a time. Writing, editing, research, quick analysis. Most of your day-to-day work.

Projects

A container for deep, ongoing work. Has its own instructions, files, and memory. Use for legal work, advertising, any specialist area you return to regularly.

Cowork

Autonomous. Runs multi-step tasks, accesses your local files, connects to tools. Use when you want it to act, not just answer.

When to use each

  • Chat: Draft an email, summarize a document, answer a question, brainstorm ideas
  • Projects: Legal matter with multiple documents, advertising campaigns, anything with deep specialist context you'll revisit
  • Cowork: Go through my emails and flag the urgent ones, run my post-session workflow, build and test a skill, access files on my computer

How to set up a project

  1. In Claude Chat, click New Project
  2. Give it a name and description (e.g., "Perway Advertising")
  3. Add Project Instructions — this is where you tell Claude who it is, what it knows about your business, and how it should behave in this context
  4. Upload relevant files — standard operating procedures, brand guidelines, scripts, templates
  5. Only upload files you'll actually use. Every file uploaded gets read on every chat — unused files burn credits.
Strategy tip: Think of each project as a specialist staff member. Your main hub handles business operations. A separate project handles advertising. Brief them separately — and brief one from the other if you need them to collaborate.

How to access SharePoint/OneDrive from Cowork

  1. Install the OneDrive desktop app on your PC if you haven't already
  2. Sync your SharePoint folder to your local drive
  3. In Cowork, use Choose a different folder to point Cowork at your OneDrive folder
  4. Cowork can now read, write, and organize files in that folder

Skills — Repeatable Workflows You Build Once

A skill is a set of instructions that tells Claude how to run a specific workflow — consistently, every time. Once built, you invoke it with a forward slash (e.g., /email-triage) and it runs.

How to install a skill

  1. Go to Customize (bottom left in Claude)
  2. Click Skills
  3. Click Add Skill > Upload a Skill
  4. Drag and drop the .skill file in
  5. Done — it's now available in all your chats

Installing your Perway Email Triage Skill

James has built a custom email triage skill for you. Once you receive it:

  1. Follow the install steps above to upload it
  2. Once installed, go to Skills and find the Perway Email Triage skill
  3. Click Edit with Claude
  4. Paste in the brief James sends you — this tells Claude how to improve the skill for your inbox
  5. Run it on a batch of your recent emails and give Claude feedback on what to change

How to invoke a skill

In any chat or Cowork, type / followed by the first few letters of the skill name. It will appear as a suggestion. Click it to invoke.

How to update a skill

Go to Customize > Skills > find the skill > click Edit with Claude. Tell it what you want changed in plain English. It updates the skill in real time.

Rule of thumb: If you do something the same way more than three times, turn it into a skill. Skills are how you build consistent, staff-level outputs without repeating yourself.

Connectors — Linking Your Tools

Connectors let Claude access and act within your existing tools — email, calendar, files, and more.

How to connect

  1. Go to Customize > Connectors > Browse Connectors
  2. Find the tool you want (Google Drive, Google Calendar, Canva, etc.)
  3. Click and authorize — it's a one-click approval for most tools
  4. Connectors built by Anthropic are safe. Check the developer name before authorizing anything unfamiliar.

Microsoft 365 — what you need to know

Microsoft 365 requires admin approval to connect. Your IT team needs to approve it through Microsoft's admin portal. Once approved:

  • Claude can search your emails and files
  • Claude can check your calendar
  • Claude cannot send emails directly — that requires a separate Make or Zapier automation (James can build this for you)

Choosing your connectors

Go through the connector list and only connect tools you actually use. There are hundreds available — most of them aren't relevant to you. A useful rule: if connecting it would save you a step you do daily, it earns its place.

A few worth knowing about: Microsoft 365 gives Claude access to your emails, calendar, and files — the most useful one for a business like yours, but requires IT approval. Google Drive and Google Calendar are straightforward one-click connects if you use them. Canva lets Claude create and edit designs directly. Zapier and Make are for building automations — useful once you're comfortable with the basics, not essential on day one.

If you're unsure whether a connector is worth it, ask Claude: "I use [tool] for [task] — would connecting it actually help me?" It'll give you a straight answer.

Scheduled Tasks in Cowork

Cowork can run tasks on a schedule — daily, weekly, or at a specific time — without you needing to prompt it each time.

How to set up a scheduled task

  1. Open Cowork
  2. Click Scheduled (left sidebar)
  3. Click New Task
  4. Invoke your skill (e.g., /email-triage)
  5. Tell it what to do and when to run it
Run my Perway email triage skill every day at 4:30pm. Look back 24 hours. Categorise emails into urgent, follow-up required, junk, and FYI. Flag anything from clients or council. Give me a summary in chat.
Note on accounts: Scheduled tasks in Cowork run from your account and use your connected tools. If Andy needs separate email triage, he'll need his own Claude account with his own connectors set up. James can walk you through this.
