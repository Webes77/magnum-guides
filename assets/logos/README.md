# Logos

The delivered Magnum AI artwork, September 2026, copied byte for byte from the
Logos group of the Magnum AI design system
(https://claude.ai/artifact/2akdAwifvokfTEYpmeWdWb). Never redraw, trace or
recolour these. Pick the file whose ink matches the ground.

| File | Use |
|---|---|
| `magnum-badge-ring.svg` | Primary badge on paper, 90px and up |
| `magnum-badge-ring-navy.svg` | Primary badge on a navy band, 90px and up |
| `magnum-badge-ring-paper.svg`, `-coral`, `-mono`, `-white` | The other colourways |
| `magnum-badge.svg`, `magnum-badge-navy.svg` | Secondary lockup, no outer ring |
| `magnum-mark.svg` | Below 90px, on paper |
| `favicon-512.png` | Favicon source |

`favicon-32.png`, `apple-touch-icon.png` (180px) and `/favicon.ico` are
straight resizes of `favicon-512.png`, nothing redrawn or recoloured.

There is no delivered small mark for a dark ground: `magnum-mark.svg` is navy
and disappears on navy, and the badge cannot go below 90px. Below 90px on a
dark ground, set the name in Oswald 700 uppercase until a reverse mark exists.
