Rules

Never mix card types

This is the one that breaks pages

A tall image card beside a short text card leaves a hole and reads as a bug. Put the archive link under the grid as text, not inside it as a card.

Understood →
Rules
  • Rust is the only accent. One accent colour per page. Gold belongs to the old system and is retired.
  • Olive never carries text. It exists for figures, ticks and confirmation marks.
  • Uppercase Oswald for every heading. Sentence case display type belongs to a different brand.
  • Every label is mono, uppercase, letter spaced, with a rule running off to the right.
  • Hard shadows, no blur, no radius. The offset shadow is the signature. Soft shadows and rounded corners are the previous system.
  • Paper always carries the grid texture. A flat paper ground looks unfinished.
  • Cards within a section share one type. All image, or all text.
  • Never ship a placeholder card. An empty section is better than advertising an empty room.
Do not
  • Introduce a fourth typeface, or Playfair, Bebas Neue, Archivo Narrow or Inter. Those came from documents that predate this system.
  • Use black and gold. Retired.
  • Restyle a document a client has already received. Deliverables stay as they were sent.
  • Change a URL that has been sent to a client, for any reason, including a redesign.
Copy the tokens

Paste this block at the top of any new page. Every value on this page comes from it.

:root{
  --paper:#EEE6D3;    /* page ground, with the grid texture */
  --paper-2:#E4DAC4;  /* cards and panels */
  --ink:#1E1B17;      /* mastheads, borders, headings, shadows */
  --body:#2B2823;     /* running text */
  --rust:#B8452A;     /* the only accent */
  --olive:#6C7A3F;    /* figures and ticks only */
  --char:#3A3630;     /* text inside cards */
  --mute:#6F675C;     /* notes and secondary lines */
  --grid:rgba(120,90,60,.13);
  --display:'Oswald','Arial Narrow','Liberation Sans Narrow',sans-serif;
  --sans:'IBM Plex Sans',system-ui,sans-serif;
  --mono:'IBM Plex Mono',ui-monospace,monospace;
}
